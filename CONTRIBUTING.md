# Contributing to OpenZone Taurians

Thanks for your interest in contributing! 🎉

## How to Contribute

1. **Fork** the repository and create your branch from `main`.
2. **Make your changes** with clear, focused commits.
3. **Test** that the app builds and runs (`bun run tauri dev`).
4. **Open a Pull Request** describing what you changed and why.

## Reporting Bugs

Open an [issue](https://github.com/bengidev/openzone-taurians/issues) with:
- A clear description of the problem
- Steps to reproduce
- Your OS and app version
- Logs or screenshots if relevant

## Feature Requests

Open an issue and tag it as a feature request. Describe the use case and the problem it solves.

## Code Style

- Frontend: TypeScript, formatted consistently.
- Backend: Rust, run `cargo fmt` and `cargo clippy`.
- Keep changes scoped and well documented.

## Commit Messages

Use clear, conventional messages (e.g. `feat:`, `fix:`, `docs:`, `chore:`).
